# mock — 클릭 가능한 목업

빌드도 서버도 필요 없다. `index.html` 을 브라우저로 열면 끝.

```
mock/
├── index.html     ← 결과물. 이 파일 하나만 열면 된다
├── build.sh       ← src/ 를 합쳐 index.html 을 만든다
├── src/
│   ├── shell.html   CSS + 화면 마크업
│   ├── data.js      목업 데이터 (역량 20 · 경험 6 · 공고 7 · 문항 10)
│   └── render.js    렌더러 · 매칭 산식 · 문장 점검 · AI 흐름 시뮬레이션
└── DESIGN.md      ← 설계 문서 (문제 정의 · AI 확장 지점 · 데이터 모델 · 검증 기록)
```

## 고칠 때

`index.html` 을 직접 고치지 말고 `src/` 를 고친 뒤 빌드한다.

```bash
./build.sh
```

빌드가 하는 일:
1. `module.exports` 같은 **Node 전용 코드 자동 제거** (검증하다 남는다)
2. `require(` · `exports.` · `__dirname` 이 남아 있으면 **빌드 실패** — 브라우저에서 스크립트 전체가 죽는다
3. `src/` 를 합쳐 `index.html` 생성
4. JS 구문 검사 + **정의 없는 CSS 클래스 경고**

4번이 실제로 버그를 세 번 잡았다 (`pre.code` · `.mono` · SVG 다이어그램 클래스가 정의 없이 쓰이고 있었다).
남아 있는 경고 `mrow · mdet · s4ex` 는 JS 선택자 전용이라 스타일이 없는 게 맞다.

## 상단 토글 두 개

- **설계 주석** — 각 UI 가 어떤 API·테이블에 대응하는지 배지로 표시된다. 켜면 네트워크 로그와
  프롬프트 입력 JSON 도 같이 뜬다. **발표 때 이걸 켜고 설명하면 화면 하나로 API 명세와 ERD 를 같이 보여줄 수 있다.**
- **다크** — 라이트/다크 전환.

## 개발 참고 탭이 하는 일

`docs/` 를 화면으로 대체한다. **표가 목업이 실제로 쓰는 `DATA` 와 `SCORE` 상수에서 그려지므로
문서와 구현이 어긋날 수 없다.** 8절 시드 데이터는 지금 데이터를 그대로 `INSERT` 254줄로 뽑아 준다 —
복사해서 `seed.sql` 로 쓰면 된다.

## 목업이 진짜로 계산하는 것 / 흉내만 내는 것

| 진짜 계산 | 흉내 |
|---|---|
| 매칭 커버리지 · 갭 판정 · 가중 평균 | LLM 응답 (고정 JSON) |
| 평가 요약 문장 · 다음 할 일 (규칙 조립) | 202 + 폴링 (setTimeout) |
| 문장 점검 8종 (전부 문자열 규칙) | 공고 수집 배치 |
| 경험 등록·수정 → 이벤트 → 재평가 상태 전이 | |

경험을 등록하거나 고치면 매칭이 실제로 움직인다. 숫자가 미리 박혀 있지 않다.
